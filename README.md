# EARTH QUEST — 失われた星の鼓動

環境問題について学べる、ブラウザーで遊ぶ一人称視点の環境RPGです。主人公の目線で町や自然の中を歩き、360°見渡しながら住民の話や調査を通じて対策を選びます。海辺と砂漠の地域を自由に探索できます。

## 遊び方

`index.html` をブラウザーで直接開くと遊べます。WebGLで描画する全画面の3D一人称視点で、マウスはクリックせず動かすだけで上下左右を見渡せます。移動は WASD、Shift を押しながら走ります。矢印キーでも視点を動かせます。画面には現在地・方角・クエスト・会話を重ねて表示し、全画面表示にも切り替えられます。スマートフォンでは画面下のタッチパッドでも移動・見回しができます。近くの住民・調査場所・出入口に向いて E、Enter、Space キーを押すと会話や移動ができます。画面の選択肢はクリックまたはキーボードで選べます。

直接開けない環境では、Python 3 が使える場合、プロジェクトのフォルダーで次のコマンドを実行します。

```sh
python3 -m http.server 8000
```

ブラウザーで `http://localhost:8000` を開いてください。

## ファイル構成

```text
index.html
css/game.css
js/
  main.js             WebGL 3D描画、移動、会話と選択肢
  areas/
    ocean.js          海エリアのストーリーと対策
    desert.js         砂漠エリアのストーリーと対策
```

エリア固有の内容は各エリアファイルにまとめ、共通の移動処理や描画から分離しています。各地域の `maps.town` と `maps.field` は21×15の地図データを実行時に2倍へ拡張し、WebGLで起伏のある地面、光と霧、雲や遠景の空、波打つ水面、木や花、岩、窓や切妻屋根の建物を描画します。歩行時には視点がわずかに揺れ、植物も風に揺らぎます。描画解像度を端末の画面密度に合わせて制限し、シーンの頂点データはエリア切り替え時だけ生成して軽快に動作するようにしています。マウス移動でクリックなしに見回し、WASDで歩き、Shiftで走ります。タッチ端末には移動パッドと視点ボタンを表示します。`index.html` はエリアファイルを共通処理より先に読み込みます。新しいエリアを追加する場合は、同じ形式のデータと処理を用意し、`js/main.js` のエリア一覧へ登録します。外部サービスやAPIは使用しません。
